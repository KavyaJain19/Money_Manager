Local Android personal money tracker.

- Edit/delete normal transactions
- Edit/delete friend payments
- Case-insensitive friend names
- Dedicated Friends screen and friend detail screen
- Person-wise due and complete history
- Friends linked to actual balance for money paid/received
- Settlement can be recorded from the Friends section
- PDF export
- Phone-oriented UI
- Same application ID and local SharedPreferences storage
