# My Money v1.5
100% Local & Offline Android personal money manager.

Updates in v1.5:
- Safe JSON data storage (eliminates corruption from quotes, special characters, or newlines in notes)
- Automatic backward compatibility migration from legacy records
- Calendar DatePicker dialog for fast, error-free date selection
- Predefined category and payment method suggestions with auto-complete
- Multi-page PDF generation (no cutoffs for long transaction histories)
- CSV / Excel spreadsheet export for viewing in Google Sheets / Microsoft Excel
- Offline JSON Backup & Restore to easily migrate or safeguard your data
- Real-time search filter in transaction history
- Friends & Due settlement tracking with name auto-complete
